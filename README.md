# Reference-Free Nanopore VHH (Nanobody) Repertoire Analysis Pipeline

A modular, reproducible Python pipeline for **de novo** analysis of nanobody (VHH)
repertoires sequenced on Oxford Nanopore, with **no reference sequence required**.

Instead of reference-based variant calling, the pipeline:
1. QC-filters raw reads,
2. Length-filters around the expected ~397 bp VHH amplicon,
3. Translates and validates ORFs,
4. Confirms VHH identity via framework motifs (and optionally ANARCI/HMM),
5. Annotates FR/CDR regions with antibody numbering (ANARCI, IMGT scheme recommended),
6. Collapses to unique nucleotide/amino-acid sequences with abundance,
7. Computes **all-vs-all internal similarity** (no external reference needed),
8. Clusters sequences (classical + optional protein-language-model embeddings),
9. Computes repertoire diversity (Shannon/Simpson/rarefaction) at the CDR level,
10. Discovers motifs and candidate novel/rare variants,
11. Serves everything through an interactive Streamlit dashboard,
12. Exports publication-ready tables and figures.

## Why reference-free?

Nanobody libraries (e.g. from immunized-animal or synthetic display libraries) do not
have a single "true" reference sequence — every read is potentially a distinct clone.
Reference-based variant callers (which assume one true haplotype ± SNPs/indels around
it) are the wrong tool. This pipeline instead treats the **repertoire itself** as the
comparison set: sequences are clustered and compared against each other, and diversity
is measured directly from the observed sequence population (an approach standard in
AIRR-seq / immune repertoire sequencing, e.g. VDJ diversity analyses in
Immcantation/pRESTO-style pipelines, adapted here for VHH single-domain format and
long-read Nanopore data).

## Modules (`utils/`)

| Module | Responsibility |
|---|---|
| `io_utils.py` | Load FASTQ/FASTA, normalize records, write outputs |
| `qc.py` | Phred quality filtering, QC plots/report |
| `length_filter.py` | Amplicon length filtering (±tolerance around 397 bp) |
| `translate.py` | 6-frame / best-ORF translation, stop-codon & frameshift detection |
| `vhh_identify.py` | Framework-motif based VHH confirmation |
| `cdr_annotation.py` | ANARCI-based FR/CDR numbering (IMGT default) |
| `unique_seqs.py` | Deduplication, copy number, abundance ranking |
| `similarity.py` | All-vs-all pairwise identity / alignment (parasail, Levenshtein) |
| `clustering.py` | Hierarchical / DBSCAN / HDBSCAN / UMAP, optional PLM embeddings |
| `diversity.py` | Shannon/Simpson/evenness/richness, rarefaction |
| `motif.py` | Motif discovery + sequence logos per CDR |
| `novel_discovery.py` | Rare/outlier/candidate-novel variant flagging |
| `report.py` | Aggregates everything into the summary report |

## Quick start

```bash
pip install -r requirements.txt
# Optional (large / not always needed): ESM-2 embeddings, HDBSCAN, ANARCI
python scripts/run_pipeline.py \
    --input data/reads.fastq \
    --outdir results/ \
    --expected-length 397 \
    --length-tolerance 0.10 \
    --min-qscore 9

streamlit run dashboard/app.py -- --results results/
```

## Notes on installation

- **ANARCI** is not `pip`-installable from PyPI in most environments; install via
  conda (`conda install -c bioconda anarci`) or from source
  (https://github.com/oxpig/ANARCI). `cdr_annotation.py` detects its absence and
  falls back to a regex/motif-based FR/CDR splitter (lower accuracy — flagged in
  output) so the rest of the pipeline still runs.
- **parasail** gives large speedups for pairwise SW/NW alignment over pure-Python
  Biopython aligners; it's optional but strongly recommended for >5,000 sequences.
- **ESM-2** (via `fair-esm` or HuggingFace `transformers`) is optional and only
  used if `--use-plm-embeddings` is passed — see the Critical Review below for
  when it's actually worth the compute cost.
